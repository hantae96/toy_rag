**※ (요약) 10만번 원자재 자재마스터 접수 후 가단가 등록 및 INFO-RECODE 등록 PROCESS**

1. 메일 上 생산운영팀 이수아 대리 자재마스터 접수 및 TIMS2 등록

2. 접수된 마스터 정보로 가단가 등록 후 INFO-RECODE 생성(원화자재 가단가 1원 / 외화자재 $ 0.01 / 10 EA)​

3. 견적 단가 추출(표준화) 및 업체 견적 요청(기구도면+인쇄시방서 첨부하여 송부)

4. 회신된 견적사항 업체 협의 후 최종단가 SAP 등록 및 기준원가(생산운영팀 이수아대리) + 표준원가(재무팀 이항건사원) 등록 요청

**1. 생산운영팀 이수아 대리 자재마스터 메일 접수 및 가단가 TIMS2 등록**

{IMAGE_0}

1-1. 생산운영팀으로부터 신규채번 자재코드에 대한 '자재마스터' 메일 접수

1-2. 등록을 위한 TIMS2 에서 '자재구매관리-자재마스터관리-자재마스터등록' 열기

1-3. 항목 中 아래 '진행상태' 에서 '구매정보 기입대기' 클릭 후 조회 → 미등록 자재마스터 LIST 조회 가능

{IMAGE_1}

1-4. 관련 정보(구매정보등록자(담당자), Pur.Group(구매그룹), Min Lot Size(MOQ), Rounding Value(1), PlndDelivery(L/T), PlanPrice(가단가 원화 1원/외화 0.01(10EA)), Price Date(현재날짜) 입력 후 맨 앞 '선택'란 체크 후 저장

{IMAGE_2}

​

**2. 가단가(Excel) 등록 및 Info-Record 등록**

2-1. TIMS2 신규자재정보 저장 후 가단가 Excel 파일에 신규코드 정보 기입

{IMAGE_3}

​2-1-1. 미등록(신규자재코드), 자재규격, 업체코드, 업체명, 발주/위탁 종류, 마스터접수일, 구매그룹, 가단가(보통 KRW 1원/USD 0.01 $ 기재), 등록요청자(연구소 담당자) 기재

2-1-2. 연구소 MC단가 확인 가능시 문의 후 기재

2-2. SAP 가단가 INFO-RECORD 생성

{IMAGE_4}

​2-2-1. T-CODE : ME11 입력 후 생성자재에 대한 Vendor(업체), Material(자재코드), Purchasing Org(1000), Plant(3000) 입력​

2-2-2. 하단의 Info category 의 경우 발주자재(=Standard), 위탁자재(=Consignment), 반제품자재(Subcontracting) 中 자재에 맞게 선택 후 최종 ENTER 2번 입력

{IMAGE_5}

2-2-3.  입력 후 상단의 Purch. Org data 1 클릭 → Deliv. time, Purch.Group(구매그룹), Standard Qty(최소발주수량), Minimum Qty(자재패킹단위수량), Tax Code(원화의 경우 부가가치세 10%로 AA입력, 외화의 경우 입력하지 않음 ), Net Price(가단가 원화자재 1원, 외화자재 $ 0.01 / 10 EA) 입력

{IMAGE_6}

2-2-4. 입력 후 왼측 상단의 Conditions 클릭 후 상기 왼측 화면에서 "PB00" 더블 클릭 → 상기 우측 화면에서 Valid From에 금일 생성일자 확인 후 더블클릭​

2-2-5. 이후 Gross Price 에 원화 1원, 외화 $ 0.01 등록 후 상단 SAVE(저장) 클릭

{IMAGE_7}

2-3. 인포 생성 후 가단가 EXCEL에 인포 생성(입력)일자 기입

2-4. IFS 기구도면/인쇄시방서 신규자재 등록 여부 확인

2-4-1. <https://ifs.idis.co.kr> 접속 후 전산팀 통해 본인 아이디/비밀번호 생성 및 로그인 후 신규자재코드 기구도면/인쇄시방서 업로드 확인

2-4-2. 기구도면/인쇄시방서 미등록 시 아래 메일과 같이 기구팀+디자인팀 IFS 등록 요청 (업로드 시 가단가 EXCEL에 업로드 일자 기입)​

{IMAGE_8}

​

**3. 견적 단가 검토 및 업체 신규자재 견적 요청**

3-1. 가단가 EXCEL, 도면, 인쇄시방서를 바탕으로 각 업체 견적 LIST 작성

3-1-1. 원자재/부자재/기계가공/검사&포장/외주가공 등 DATA 입력 후 아래와 같이 표준화 단가 추출 (비표준화 자재는 업체와 협의)

{IMAGE_9}

3-2. 단품/ASSY에 따라 구분하여 견적단가 산출

3-2-1. 기존 기구도면 존재하는 파생자재의 경우 별도샘플 x, 기존 도면자재가 없는 신규자재의 경우 신규샘플 O -> 접수 후 형상 및 중량 확인 필요!(사출의 경우 필수)

3-3. 견적단가 산출 후 검토한 항목 및 SPEC으로 견적서 작성 (사진은 확대해서 보기 바람)

3-3-1. 견적 사유, 특이사항(설계변경 등), 가공별 비고 란 세부적으로 작성

{IMAGE_10}

3-4. 작성된 견적서를 도면+인쇄시방서(없는경우 생략)와 함께 업체 메일로 송부

**4. 업체 협의 후 최종 산출된 단가 SAP 입력 후 기준원가,표준원가 입력 요청**

4-1. 견적서 업체 메일 송부 후 견적단가 동의 시 업체 측 견적서 접수

- 1차 메일로 PDF, EXCEL 등 직인 스캔본 접수 후 납품 시 날인 원본 접수 → 협의단가 이상 없을 시 견적서 날인본 팀장님 보고 후 파일철 진행

4-2. 가단가 EXCEL파일 실제단가, MOQ 입력 후 기준단가/표준원가 생산운영팀(기준정보)/재무팀 입력요청

{IMAGE_11}

4-3. 기준단가/표준원가 입력 요청 메일 발송 후 가단가 EXCEL 파일 입력 요청일자 기재 후 전체 CELL 노란색 음영

4-3-1. 노란색 음영 후 보고 및 견적이 완료되었으므로, 가단가 EXCEL 상단의 보고완료 LIST로 CELL 이동

4-4. SAP INFO-RECORD 단가수정

4-4-1. SAP T-CODE : ME12 입력 후 생성자재에 대한 단가수정 진행

{IMAGE_12}

4-4-2. Vendor(업체), Material(자재코드), Purchasing Org(1000), Pland(3000) 입력 후 인포레코드 수정 진행

{IMAGE_13}

4-4-3. 하단의 Info category 의 경우 발주자재(=Standard), 위탁자재(=Consignment), 반제품자재(Subcontracting) 中 자재에 맞게 선택 후 최종 ENTER 2번 입력

{IMAGE_14}

4-4-4. 입력 후 왼측 상단의 Conditions 클릭 후 상기 왼측 화면에서 PB00 더블 클릭

4-4-5. 이후 상기 우측 화면에서 NEW Validity period 클릭 후 견적산출(수정) 단가 입력 → 이후 Vaild From 일자 확인 후 상단 SAVE(저장) 클릭
